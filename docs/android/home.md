앱을 열면 가장 먼저 보이는 화면으로, 자주 확인하는 정보를 한 화면에 모아서 보여줍니다.

<img src="/img/android/ko/home.png" alt="홈 화면" width="320" />

## 주요 정보

- **날씨**: 현재 기온과 상태(맑음·흐림·비·눈 등)를 화면 상단에 문구와 아이콘으로 보여줍니다.
- **셔틀버스 출발 정보**: 출발지(기숙사/한대앞/예술인/중앙역 등)를 선택하면 다음 출발 시각과 남은 시간이 카드로 표시되고, 이어서 탈 수 있는 전철·버스 환승 정보가 함께 붙어서 보입니다.
- **전체 시간표**: 셔틀 카드 상단의 **전체 시간표**를 누르면 해당 노선의 전체 배차 시간표로 이동합니다. 자세한 내용은 [셔틀버스](./shuttle) 문서를 참고하세요.
- **학식 메뉴 미리보기**: 메뉴 카드를 눌러 조식/중식/석식 기준으로 오늘의 학식 메뉴를 바로 확인할 수 있습니다.

## 빠른 설정

화면 하단의 **홈 설정** 버튼을 누르면 아래 항목을 바로 조정할 수 있습니다.

- 재학생 현황 표시 여부
- 50번 버스 환승 정보 표시 여부
- 전철 환승 목적지 선택
- 레거시 셔틀 화면으로 전환

:::tip
자주 타는 노선이 바뀌었다면 빠른 설정에서 목적지만 변경하면 되고, 앱 전체 설정으로 들어갈 필요는 없습니다.
:::
