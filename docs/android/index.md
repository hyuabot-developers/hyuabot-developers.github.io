휴아봇 Android 앱 사용설명서입니다. 앱 하단 내비게이션은 **홈 · 버스 · 전철 · 학식 · 캠퍼스** 5개 탭으로 구성되어 있고, 왼쪽 사이드바에서 화면별 안내를 확인할 수 있습니다.

| 화면 | 설명 |
| --- | --- |
| [홈](/docs/android/home) | 날씨, 셔틀 출발 정보, 학식 미리보기, 환승 정보를 한눈에 모아 보는 첫 화면 |
| [셔틀버스](/docs/android/shuttle) | 정류장별 실시간 출발 시간 조회 및 전체 시간표 |
| [버스](/docs/android/bus) | 서울·수원·기타·시내 노선 실시간 도착 정보 및 시간표 |
| [전철](/docs/android/subway) | 한대앞역 4호선·수인분당선 실시간 도착 정보 및 시간표 |
| [학식](/docs/android/cafeteria) | 교내 식당별 조식·중식·석식 메뉴 |
| [캠퍼스](/docs/android/campus) | 열람실 좌석, 캠퍼스 지도, 교내 연락처, 학사력, 공지사항, 문의하기 |
| [설정](/docs/android/settings) | 캠퍼스·언어·테마 등 앱 환경설정 |
| [홈 화면 위젯](/docs/android/widgets) | 셔틀·학식 정보를 홈 화면에서 바로 확인 |
| [Wear OS 앱](/docs/android/wear-os) | 갤럭시 워치 등 Wear OS 기기용 셔틀 정보 |
