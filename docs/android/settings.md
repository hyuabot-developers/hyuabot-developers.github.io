**메뉴 → 설정**에서 앱 환경을 조정합니다.

| 항목 | 설명 |
| --- | --- |
| 캠퍼스 선택 | 서울캠퍼스 / ERICA캠퍼스 중 내가 재학 중인 캠퍼스를 선택합니다 |
| 언어 설정 | 한국어 · English · 日本語 · 中文 중 앱 표시 언어를 선택합니다 |
| 테마 설정 | 라이트 · 다크 · 시스템 설정 중 화면 테마를 선택합니다 |
| 개인정보 처리방침 | 개인정보 처리방침 전문을 웹뷰로 확인합니다 |
| 오픈소스 라이선스 | 앱에 사용된 오픈소스 라이브러리 목록을 확인합니다 |
| 코치마크 초기화 | 화면별 사용법 안내(코치마크)를 처음부터 다시 볼 수 있도록 초기화합니다 |
| 분석 데이터 수집 동의 | 앱 개선을 위한 익명 사용 데이터 수집 동의 여부를 켜고 끕니다 |
| 앱 정보 | 앱 버전 등 기본 정보를 확인합니다 |

:::tip
재학 중인 캠퍼스가 바뀌었거나 다른 캠퍼스 정보를 확인하고 싶다면 캠퍼스 선택만 변경하면, 셔틀·학식 등 캠퍼스별 데이터가 함께 전환됩니다.
:::
