휴아봇 iOS 앱 사용설명서입니다. 앱 하단 탭은 **셔틀 · 버스 · 전철 · 학식 · 캠퍼스** 5개로 구성되어 있습니다. Android와 달리 별도의 "홈" 탭이 없고, 날씨·셔틀 출발정보·환승정보·학식 미리보기를 모은 홈 화면이 **셔틀** 탭 안에 들어있습니다.

| 화면 | 설명 |
| --- | --- |
| [셔틀](/docs/ios/shuttle) | 날씨·셔틀 출발정보·환승정보·학식 미리보기를 모은 홈 화면 겸 셔틀버스 실시간 정보 |
| [버스](/docs/ios/bus) | 정류장별 실시간 도착 정보 및 시간표 |
| [전철](/docs/ios/subway) | 역별 실시간 도착 정보 및 시간표 |
| [학식](/docs/ios/cafeteria) | 교내 식당별 조식·중식·석식 메뉴 |
| [캠퍼스](/docs/ios/campus) | 지도, 열람실, 학사일정, 연락처 등 부가 기능 |
| [설정](/docs/ios/settings) | 캠퍼스·언어·테마 등 앱 환경설정 |
| [위젯 & Live Activity](/docs/ios/widgets) | 셔틀·학식·환승 정보를 홈 화면과 잠금화면에서 바로 확인 |
