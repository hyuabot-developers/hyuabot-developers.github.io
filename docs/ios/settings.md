**캠퍼스 → 설정**에서 앱 환경을 조정합니다.

| 항목 | 설명 |
| --- | --- |
| 캠퍼스 설정 | 서울캠퍼스 / ERICA캠퍼스 중 내가 재학 중인 캠퍼스를 선택합니다 |
| 테마 설정 | 라이트 · 다크 · 시스템 설정 중 화면 테마를 선택합니다 |
| 언어 설정 | 기기(iOS)의 시스템 언어 설정으로 이동해 앱 표시 언어를 바꿉니다 |
| 앱 분석 데이터 수집 | 앱 개선을 위한 익명 사용 데이터 수집 동의 여부를 켜고 끕니다 |
| 기능 안내 다시 보기 | 앱의 코치마크(사용법 안내)를 다시 표시합니다 |
| 개인정보처리방침 | 수집 정보와 이용 목적을 확인합니다 |
| 오픈소스 라이선스 | 앱에서 사용하는 오픈소스 소프트웨어를 확인합니다 |
| 개발자 정보 | 개발자 관련 정보를 확인합니다 |
| 앱 버전 정보 | 현재 설치된 앱 버전을 확인합니다 |

:::tip
재학 중인 캠퍼스가 바뀌었거나 다른 캠퍼스 정보를 확인하고 싶다면 캠퍼스 설정만 변경하면, 셔틀·학식 등 캠퍼스별 데이터가 함께 전환됩니다.
:::

:::info
Android 앱은 언어 설정을 앱 안에서 직접 바꿀 수 있지만, iOS 앱은 기기의 시스템 언어 설정을 따릅니다.
:::
