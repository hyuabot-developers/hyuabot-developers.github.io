This is the user guide for the HYUabot Android app. The bottom navigation bar has five tabs: **Home · Bus · Subway · Cafeteria · Campus**. You can find screen-by-screen instructions in the left sidebar.

| Screen | Description |
| --- | --- |
| [Home](/docs/android/home) | The main screen that brings together weather, shuttle departure info, cafeteria preview, and transit transfer info at a glance |
| [Shuttle Bus](/docs/android/shuttle) | Real-time departure times and full timetables by stop |
| [Bus](/docs/android/bus) | Real-time arrival info and timetables for Seoul, Suwon, other, and local routes |
| [Subway](/docs/android/subway) | Real-time arrival info and timetables for Line 4 and Suinbundang Line at Hanyang University (Ansan) Station |
| [Cafeteria](/docs/android/cafeteria) | Breakfast, lunch, and dinner menus for each on-campus dining hall |
| [Campus](/docs/android/campus) | Reading room seats, campus map, campus contacts, academic calendar, notices, and contact us |
| [Settings](/docs/android/settings) | App preferences including campus, language, and theme |
| [Home Screen Widgets](/docs/android/widgets) | Check shuttle and cafeteria info directly from your home screen |
| [Wear OS App](/docs/android/wear-os) | Shuttle info for Wear OS devices such as Galaxy Watch |
