Check the menu for each on-campus dining hall from the **Cafeteria** tab in the bottom navigation bar.

<img src="/img/ios/ko/cafeteria.png" alt="Cafeteria screen" width="320" />

## Menu Lookup

- The screen is divided into Breakfast, Lunch, and Dinner tabs.
- You can compare the menus of several on-campus dining halls on one screen and check detailed information (operating hours, etc.) for each dining hall.

:::info
You can also preview today's cafeteria menu from the Home View in the Shuttle tab. Navigate to the Cafeteria tab only when you want to compare menus across all dining halls.
:::
