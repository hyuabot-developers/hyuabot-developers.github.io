This is the user guide for the HYUabot iOS app. The bottom tab bar has five tabs: **Shuttle · Bus · Subway · Cafeteria · Campus**. Unlike Android, there is no dedicated "Home" tab — the home view that brings together weather, shuttle departure info, transfer info, and cafeteria preview is built into the **Shuttle** tab.

| Screen | Description |
| --- | --- |
| [Shuttle](/docs/ios/shuttle) | Home view combining weather, shuttle departure info, transfer info, and cafeteria preview, plus real-time shuttle bus info |
| [Bus](/docs/ios/bus) | Real-time arrival info and timetables by stop |
| [Subway](/docs/ios/subway) | Real-time arrival info and timetables by station |
| [Cafeteria](/docs/ios/cafeteria) | Breakfast, lunch, and dinner menus for each on-campus dining hall |
| [Campus](/docs/ios/campus) | Additional features including maps, reading rooms, academic calendar, and contacts |
| [Settings](/docs/ios/settings) | App preferences including campus, language, and theme |
| [Widgets & Live Activity](/docs/ios/widgets) | Check shuttle, cafeteria, and transfer info directly from the home screen and lock screen |
