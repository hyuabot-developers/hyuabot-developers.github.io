Adjust app preferences from **Campus → Settings**.

<img src="/img/ios/ko/settings.png" alt="Settings screen" width="320" />

| Item | Description |
| --- | --- |
| Campus Settings | Select the campus you are enrolled in: Seoul Campus or ERICA Campus |
| Theme Settings | Choose the screen theme: Light, Dark, or System |
| Language Settings | Navigate to the device (iOS) system language settings to change the app display language |
| App Analytics Data Collection | Toggle consent for anonymous usage data collection for app improvement |
| Show Feature Guide Again | Redisplay the app's coach marks (usage tutorial) |
| Privacy Policy | Review what data is collected and how it is used |
| Open Source Licenses | View the open source software used in the app |
| Developer Info | View developer-related information |
| App Version | Check the currently installed app version |

:::tip
If your enrolled campus has changed or you want to view information for a different campus, simply change the Campus Setting and all campus-specific data such as shuttle and cafeteria will switch accordingly.
:::

:::info
On the Android app, you can change the language directly within the app. On the iOS app, the app follows the device system language setting.
:::
