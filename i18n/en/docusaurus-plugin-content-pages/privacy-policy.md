# HYUabot Privacy Policy

HYUabot ("the Service") is an **unofficial student project** operated by an individual (team) who is a Hanyang University student, and has no official affiliation with Hanyang University or any of its subordinate organizations. The operator of the Service ("the Operator") values users' personal information and has established and disclosed this Privacy Policy in order to comply with the Personal Information Protection Act and other applicable laws.

## 1. Personal Information Collected and Collection Methods

The Service does not provide sign-up or login features, and does not separately collect personally identifiable information such as email addresses or student ID numbers. However, the following information may be automatically generated and collected in the course of providing and improving the Service.

| Category | Items Collected | Collection Method | Notes |
| --- | --- | --- | --- |
| App usage statistics | Anonymous usage records (screen visits, feature usage frequency, etc.) | Firebase Analytics (Google) | Consent to collection can be turned off at any time in the app settings |
| Advertising identifier (AD ID) | Android advertising identifier | Firebase Analytics (Google) | Collected on Android only; can be turned off in the app settings. Not used for advertising purposes |
| Error/crash information | Crash logs, device model, OS/app version, and other diagnostic information | Firebase Crashlytics (Google) | Used to improve app stability |
| Location information | GPS coordinates | Collected via the device's location permission | **Processed only on the device and is never transmitted to or stored on a server.** Used solely to automatically determine the nearest shuttle bus stop; the Service can still be used normally by manually selecting a stop even if location permission is not granted |
| Notification subscription information | Topic subscription status such as reading room notifications | Firebase Cloud Messaging (FCM) / APNs | Operates via anonymous topic subscription without any information that identifies the user, and no device token is registered on any separate server |
| App settings | Favorite stops/buses, notification settings, etc. | User input | Stored only locally on the user's device and never transmitted to a server |

## 2. Purpose of Collection and Use of Personal Information

Collected information is used only for the following purposes.

1. Providing the shuttle/commuter bus and academic information service and convenience features (e.g., automatic detection of the nearest stop)
2. Sending notifications requested by the user, such as reading room seat availability
3. Improving features and diagnosing/fixing errors through analysis of service usage
4. Handling inquiries and complaints

## 3. Provision of Personal Information to Third Parties

The Operator does not, in principle, provide users' information to external parties. However, the app usage statistics, error diagnostics, and notification features described in Section 1 are processed through the following external service (data processing entrusted).

- **Google Firebase** (Analytics, Crashlytics, Cloud Messaging): A service provided by Google LLC, with servers located in the United States. Relevant information is transmitted only for the purposes of each feature. For details, please refer to [Google's Privacy Policy](https://policies.google.com/privacy).

The Service does not use any advertising SDK and does not provide collected information to third parties for advertising purposes.

## 4. Retention and Use Period of Personal Information

- App usage statistics and error diagnostic information are retained according to Firebase's policies, and the Operator does not separately store this information in a way that identifies individual users.
- Location information and app settings are stored only locally on the user's device and are deleted together when the app is deleted or the device data is reset.
- Contact information such as email addresses collected through inquiries is destroyed without delay after the inquiry has been processed.

## 5. Users' Rights and How to Exercise Them

Users can control the collection of personal information in the following ways.

- The "app analytics data collection" consent can be turned on or off at any time in the app's settings menu.
- Location permission can be denied or withdrawn at any time in the device settings; the Service can still be used normally by manually selecting a stop in this case.
- Push notification permission can be turned off at any time in the device settings.
- Inquiries, requests to view, or requests to delete personal information can be made using the contact information below.

## 6. Measures to Ensure the Security of Personal Information

The Operator takes the following measures to prevent users' information from being lost, stolen, leaked, or altered.

- Sensitive data such as location information is processed only on the device and is never transmitted to a server
- App usage statistics and error diagnostics are processed through a trusted external service (Google Firebase), and only the minimum necessary information is collected
