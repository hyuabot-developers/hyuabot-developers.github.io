下部ナビゲーションの**学食**タブで学内食堂ごとのメニューを確認します。

<img src="/img/android/ko/cafeteria.png" alt="学食画面" width="320" />

## メニュー確認

- **朝食・昼食・夕食**のタブに分かれています。
- 教職員食堂、学生食堂、創意人材院食堂、創業保育センターなど学内の複数の食堂のメニューと価格を1画面で比較できます。各食堂名の横にある情報アイコンで営業時間を確認できます。
- 画面下部の矢印で日付を移動して別の日のメニューを確認でき、**共有**ボタンで今日の献立を共有できます。

:::info
ホーム画面でも今日の学食メニューを朝食/昼食/夕食の基準でプレビューできます。全食堂のメニューを比較したい場合のみ学食タブに移動してください。
:::
