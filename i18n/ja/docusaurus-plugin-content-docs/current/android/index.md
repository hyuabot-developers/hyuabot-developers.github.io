HYUabotのAndroidアプリ ユーザーガイドです。アプリ下部のナビゲーションは**ホーム・バス・電車・学食・キャンパス**の5つのタブで構成されており、左サイドバーで各画面の説明を確認できます。

| 画面 | 説明 |
| --- | --- |
| [ホーム](/docs/android/home) | 天気、シャトル出発情報、学食プレビュー、乗換情報をひとめで確認できる最初の画面 |
| [シャトルバス](/docs/android/shuttle) | 停留所ごとのリアルタイム出発時刻表示および全時刻表 |
| [バス](/docs/android/bus) | ソウル・水原・その他・市内路線のリアルタイム到着情報および時刻表 |
| [電車](/docs/android/subway) | 漢大前駅の4号線・水仁盆唐線リアルタイム到着情報および時刻表 |
| [学食](/docs/android/cafeteria) | 学内食堂ごとの朝食・昼食・夕食メニュー |
| [キャンパス](/docs/android/campus) | 閲覧室座席、キャンパスマップ、学内連絡先、学事日程、お知らせ、お問い合わせ |
| [設定](/docs/android/settings) | キャンパス・言語・テーマなどのアプリ環境設定 |
| [ホーム画面ウィジェット](/docs/android/widgets) | シャトル・学食情報をホーム画面で素早く確認 |
| [Wear OS アプリ](/docs/android/wear-os) | Galaxy Watchなど Wear OS 端末用のシャトル情報 |
