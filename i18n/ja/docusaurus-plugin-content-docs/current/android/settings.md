**キャンパス → 設定**でアプリの環境を調整します。

<img src="/img/android/ko/settings.png" alt="設定画面" width="320" />

| 項目 | 説明 |
| --- | --- |
| キャンパス設定 | ソウルキャンパス / ERICAキャンパスのうち、在学中のキャンパスを選択します |
| 言語設定 | 韓国語・英語(English)・日本語(日本語)・中国語(中文)の中からアプリの表示言語を選択します |
| テーマ設定 | 自動・ライト・ダークの中から画面テーマを選択します |
| アプリ情報 | アプリバージョンなどの基本情報を確認します |
| 個人情報処理方針 | 収集情報と利用目的を確認します |
| オープンソースライセンス | アプリで使用しているオープンソースソフトウェアを確認します |
| 機能ガイドを再表示 | アプリのコーチマーク（使い方ガイド）を再度表示します |
| アプリ分析データ収集 | アプリ改善のための匿名利用データ・広告識別子(AD ID)の収集に同意するかを切り替えます |

## キャンパス設定

<img src="/img/android/ko/dialog-campus-setting.png" alt="キャンパス設定ダイアログ" width="320" />

ERICA・ソウルのいずれかを選ぶと、シャトル・学食などのキャンパス別データが一緒に切り替わります。

## 言語設定

<img src="/img/android/ko/dialog-language-setting.png" alt="言語設定ダイアログ" width="320" />

選択した言語は端末のシステム言語に関わらず、アプリのみに適用されます。

## テーマ設定

<img src="/img/android/ko/dialog-theme-setting.png" alt="テーマ設定ダイアログ" width="320" />

**自動**を選択すると、端末のダークモード設定に従います。

:::tip
在学中のキャンパスが変わった場合や他のキャンパスの情報を確認したい場合は、キャンパス設定だけ変更すれば、シャトル・学食などのキャンパス別データが一緒に切り替わります。
:::
