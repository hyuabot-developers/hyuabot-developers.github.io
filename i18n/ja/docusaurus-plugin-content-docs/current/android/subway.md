下部ナビゲーションの**電車**タブで漢大前駅のリアルタイム到着情報を確認します。

<img src="/img/android/ko/subway.png" alt="電車画面" width="320" />

## リアルタイム検索

- **4号線**と**水仁盆唐線**のタブに分かれており、各方面（例: 舎堂・堂高介行 / 安山・烏耳島行）ごとに次の電車までの残り時間と経由情報が表示されます。
- **快速乗換**タブで乗換所要時間を考慮したおすすめ電車をすぐに確認できます。
- **全時刻表を見る**でその方面の全運行時刻表を確認できます。
