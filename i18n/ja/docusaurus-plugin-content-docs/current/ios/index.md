HYUabotのiOSアプリ ユーザーガイドです。アプリ下部のタブは**シャトル・バス・電車・学食・キャンパス**の5つで構成されています。Androidとは異なり別途「ホーム」タブはなく、天気・シャトル出発情報・乗換情報・学食プレビューをまとめたホーム画面が**シャトル**タブの中に含まれています。

| 画面 | 説明 |
| --- | --- |
| [シャトル](/docs/ios/shuttle) | 天気・シャトル出発情報・乗換情報・学食プレビューをまとめたホーム画面兼シャトルバスリアルタイム情報 |
| [バス](/docs/ios/bus) | 停留所ごとのリアルタイム到着情報および時刻表 |
| [電車](/docs/ios/subway) | 駅ごとのリアルタイム到着情報および時刻表 |
| [学食](/docs/ios/cafeteria) | 学内食堂ごとの朝食・昼食・夕食メニュー |
| [キャンパス](/docs/ios/campus) | マップ、閲覧室、学事日程、連絡先などの各種機能 |
| [設定](/docs/ios/settings) | キャンパス・言語・テーマなどのアプリ環境設定 |
| [ウィジェット & Live Activity](/docs/ios/widgets) | シャトル・学食・乗換情報をホーム画面とロック画面で素早く確認 |
