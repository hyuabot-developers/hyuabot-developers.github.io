**キャンパス → 設定**でアプリの環境を調整します。

<img src="/img/ios/ko/settings.png" alt="設定画面" width="320" />

| 項目 | 説明 |
| --- | --- |
| キャンパス設定 | ソウルキャンパス / ERICAキャンパスのうち、在学中のキャンパスを選択します |
| テーマ設定 | ライト・ダーク・システム設定の中から画面テーマを選択します |
| 言語設定 | 端末（iOS）のシステム言語設定に移動してアプリの表示言語を変更します |
| アプリ分析データ収集 | アプリ改善のための匿名利用データ収集に同意するかを切り替えます |
| 機能ガイドを再表示 | アプリのコーチマーク（使い方ガイド）を再度表示します |
| 個人情報処理方針 | 収集情報と利用目的を確認します |
| オープンソースライセンス | アプリで使用しているオープンソースソフトウェアを確認します |
| 開発者情報 | 開発者に関する情報を確認します |
| アプリバージョン情報 | 現在インストールされているアプリのバージョンを確認します |

:::tip
在学中のキャンパスが変わった場合や他のキャンパスの情報を確認したい場合は、キャンパス設定だけ変更すれば、シャトル・学食などのキャンパス別データが一緒に切り替わります。
:::

:::info
AndroidアプリはアプリのSETTINGS内で直接言語設定を変更できますが、iOSアプリは端末のシステム言語設定に従います。
:::
