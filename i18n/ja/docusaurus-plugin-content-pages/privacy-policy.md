# HYUabot（휴아봇）プライバシーポリシー

本プライバシーポリシーは、Google Playに掲載されているAndroidアプリ「휴아봇」（英語名：HYUabot）に適用されます。

휴아봇のGoogle Play開発者表示名は「KW3102」であり、個人開発者のイ・ジョンイン（이정인）が運営しています。휴아봇は漢陽大学校およびその関連機関と公式な関係のない、非公式の学生プロジェクトです。運営者は利用者の個人情報を重視し、個人情報保護法など関連法令を遵守するため、以下のとおりプライバシーポリシーを策定・公開します。

## 1. 収集する個人情報の項目および収集方法

本サービスは会員登録・ログイン機能を提供しておらず、メールアドレスや学籍番号など個人を識別できる情報を別途収集していません。ただし、サービスの提供および改善の過程で、以下の情報が自動的に生成・収集される場合があります。

| 区分 | 収集項目 | 収集方法 | 備考 |
| --- | --- | --- | --- |
| アプリ利用統計 | 匿名の利用記録（画面訪問、機能利用頻度など） | Firebase Analytics（Google） | アプリの設定でいつでも収集への同意をオフにできます |
| 広告識別子（AD ID） | Android広告識別子 | Firebase Analytics（Google） | Androidのみで収集され、アプリの設定でオフにできます。広告配信の目的には使用しません |
| エラー・クラッシュ情報 | クラッシュログ、端末モデル、OS・アプリバージョンなどの診断情報 | Firebase Crashlytics（Google） | アプリの安定性向上のために使用します |
| 位置情報 | GPS座標 | 端末の位置情報許可を通じて収集 | **端末内でのみ処理され、サーバーへ送信・保存されることはありません。** 最寄りのシャトルバス停留所を自動的に算出する目的にのみ使用され、位置情報の許可をしなくても停留所を直接選択してサービスを正常にご利用いただけます |
| 通知の購読情報 | 自習室通知などトピック（Topic）の購読状況 | Firebase Cloud Messaging（FCM）/APNs | 利用者を識別できる情報を伴わない匿名のトピック購読方式で動作し、別途のサーバーに端末トークンを登録することはありません |
| アプリの設定値 | お気に入りの停留所・バス、通知設定など | 利用者の入力 | 利用者の端末内にのみ保存され、サーバーへ送信されません |

## 2. 個人情報の収集および利用目的

収集した情報は、以下の目的にのみ利用します。

1. シャトルバス・通学バスおよび学事情報サービスの提供と、最寄りの停留所の自動認識などの利便機能の提供
2. 自習室の空席状況など、利用者が申請した通知の送信
3. サービス利用状況の分析による機能改善およびエラーの診断・修正
4. お問い合わせおよび苦情の処理

## 3. 個人情報の第三者提供

運営者は原則として利用者の情報を外部に提供しません。ただし、上記1項に記載したアプリ利用統計、エラー診断、通知送信の各機能は、以下の外部サービス（処理委託先）を通じて処理されます。

- **Google Firebase**（Analytics、Crashlytics、Cloud Messaging）：米国にサーバーを置くGoogle LLCが提供するサービスであり、関連情報は各機能の提供目的にのみ伝達されます。詳細は[Googleのプライバシーポリシー](https://policies.google.com/privacy)をご参照ください。

本サービスは広告配信のためのSDKを使用しておらず、収集した情報を広告目的で第三者に提供することはありません。

## 4. 個人情報の保有および利用期間

- アプリ利用統計・エラー診断情報はFirebaseの方針に従って保管され、運営者はこれらの情報を利用者個人を識別する形で別途保管することはありません。
- 位置情報およびアプリの設定値は利用者の端末内にのみ保存され、アプリを削除するか端末データを初期化すると同時に削除されます。
- お問い合わせを通じて収集したメールアドレスなどの連絡先情報は、対応完了後、遅滞なく破棄します。

## 5. 利用者の権利とその行使方法

利用者は以下の方法で個人情報の収集を制御できます。

- アプリ内の設定メニューから「アプリ分析データの収集」への同意をいつでもオン・オフできます。
- 端末の設定で位置情報の許可を拒否またはいつでも撤回でき、その場合でも停留所を直接選択してサービスを正常にご利用いただけます。
- 端末の設定でプッシュ通知の許可をいつでもオフにできます。
- 個人情報に関するお問い合わせ、開示、削除のご請求は、以下の連絡先までお願いいたします。

## 6. 個人情報の安全性確保のための措置

運営者は、利用者の情報が紛失・盗難・漏洩・改ざんされないよう、以下のような措置を講じています。

- 位置情報などの機微なデータは端末内でのみ処理し、サーバーへ送信しません
- アプリ利用統計・エラー診断は信頼できる外部サービス（Google Firebase）を通じて処理し、必要最小限の情報のみを収集します
