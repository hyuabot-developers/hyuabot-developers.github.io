这是HYUabot Android 应用的使用说明书。应用底部导航栏由**首页 · 公交 · 地铁 · 食堂 · 校园**共5个标签组成，可在左侧边栏查看各页面的使用说明。

| 页面 | 说明 |
| --- | --- |
| [首页](/docs/android/home) | 汇集天气、校车出发信息、食堂预览、换乘信息的主界面 |
| [校车](/docs/android/shuttle) | 各站点实时出发时间查询及完整时刻表 |
| [公交](/docs/android/bus) | 首尔·水原·其他·市内线路的实时到站信息及时刻表 |
| [地铁](/docs/android/subway) | 汉大前站4号线·水仁盆唐线实时到站信息及时刻表 |
| [食堂](/docs/android/cafeteria) | 校内各食堂的早餐·午餐·晚餐菜单 |
| [校园](/docs/android/campus) | 阅览室座位、校园地图、校内联系方式、校历、公告、联系我们 |
| [设置](/docs/android/settings) | 校区·语言·主题等应用环境设置 |
| [主屏幕小组件](/docs/android/widgets) | 在主屏幕直接查看校车·食堂信息 |
| [Wear OS 应用](/docs/android/wear-os) | 适用于 Galaxy Watch 等 Wear OS 设备的校车信息 |
