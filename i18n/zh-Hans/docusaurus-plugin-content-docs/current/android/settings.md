在**校园 → 设置**中调整应用环境。

<img src="/img/android/ko/settings.png" alt="设置界面" width="320" />

| 选项 | 说明 |
| --- | --- |
| 校区设置 | 在首尔校区 / ERICA校区中选择您就读的校区 |
| 语言设置 | 在韩语 · 英语(English) · 日语(日本語) · 中文(中文) 中选择应用显示语言 |
| 主题设置 | 在自动 · 浅色 · 深色中选择界面主题 |
| 应用信息 | 查看应用版本等基本信息 |
| 隐私政策 | 查看收集信息及使用目的 |
| 开源许可证 | 查看应用使用的开源软件 |
| 重新查看功能引导 | 重新显示应用的功能引导（使用说明） |
| 应用分析数据收集 | 开关用于改善应用的匿名使用数据及广告标识符（AD ID）收集同意状态 |

## 校区设置

<img src="/img/android/ko/dialog-campus-setting.png" alt="校区设置对话框" width="320" />

选择ERICA或首尔其中一个后，校车·食堂等各校区数据将一并切换。

## 语言设置

<img src="/img/android/ko/dialog-language-setting.png" alt="语言设置对话框" width="320" />

所选语言与设备系统语言无关，仅应用于本应用。

## 主题设置

<img src="/img/android/ko/dialog-theme-setting.png" alt="主题设置对话框" width="320" />

选择**自动**后，将跟随设备的深色模式设置。

:::tip
如果就读校区发生变化，或想查看其他校区的信息，只需更改校区设置，校车·食堂等各校区数据将一并切换。
:::
