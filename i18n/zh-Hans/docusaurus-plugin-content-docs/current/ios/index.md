这是HYUabot iOS 应用的使用说明书。应用底部标签由**校车 · 公交 · 地铁 · 食堂 · 校园**共5个组成。与 Android 不同，没有独立的"首页"标签，汇集天气·校车出发信息·换乘信息·食堂预览的主界面位于**校车**标签内。

| 页面 | 说明 |
| --- | --- |
| [校车](/docs/ios/shuttle) | 汇集天气·校车出发信息·换乘信息·食堂预览的主界面兼校车实时信息 |
| [公交](/docs/ios/bus) | 各站点实时到站信息及时刻表 |
| [地铁](/docs/ios/subway) | 各站实时到站信息及时刻表 |
| [食堂](/docs/ios/cafeteria) | 校内各食堂的早餐·午餐·晚餐菜单 |
| [校园](/docs/ios/campus) | 地图、阅览室、校历、联系方式等附加功能 |
| [设置](/docs/ios/settings) | 校区·语言·主题等应用环境设置 |
| [小组件 & Live Activity](/docs/ios/widgets) | 在主屏幕和锁定屏幕直接查看校车·食堂·换乘信息 |
