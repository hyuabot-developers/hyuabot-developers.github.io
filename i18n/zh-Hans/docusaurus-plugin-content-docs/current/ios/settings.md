在**校园 → 设置**中调整应用环境。

<img src="/img/ios/ko/settings.png" alt="设置界面" width="320" />

| 选项 | 说明 |
| --- | --- |
| 校区设置 | 在首尔校区 / ERICA校区中选择您就读的校区 |
| 主题设置 | 在浅色 · 深色 · 跟随系统中选择界面主题 |
| 语言设置 | 跳转至设备（iOS）的系统语言设置，更改应用显示语言 |
| 应用分析数据收集 | 开关用于改善应用的匿名使用数据收集同意状态 |
| 重新查看功能引导 | 重新显示应用的功能引导（使用说明） |
| 隐私政策 | 查看收集信息及使用目的 |
| 开源许可证 | 查看应用使用的开源软件 |
| 开发者信息 | 查看开发者相关信息 |
| 应用版本信息 | 查看当前安装的应用版本 |

:::tip
如果就读校区发生变化，或想查看其他校区的信息，只需更改校区设置，校车·食堂等各校区数据将一并切换。
:::

:::info
Android 应用可在应用内直接更改语言设置，而 iOS 应用则跟随设备的系统语言设置。
:::
